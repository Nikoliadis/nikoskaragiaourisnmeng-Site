# Database

Όλα τα **δεδομένα** της ιστοσελίδας. Τίποτα εδώ δεν μπαίνει στο git — είναι ο
φάκελος που κρατάς σε backup.

| Περιεχόμενο | Τι είναι |
|---|---|
| `db.sqlite3` | Η βάση: κατηγορίες, έγγραφα, ανακοινώσεις, μηνύματα. |
| `protected_media/` | Τα ανεβασμένα αρχεία, με τυχαία ονόματα UUID. Δεν σερβίρονται ποτέ απευθείας — μόνο μέσω `/lipsi/<id>/`. |
| `media/` | Δημόσιες εικόνες ανακοινώσεων. Δημιουργείται με το πρώτο ανέβασμα. |

**Τα migrations δεν είναι εδώ.** Είναι κώδικας, όχι δεδομένα, και ζουν στο
`Backend/content/migrations/` μαζί με την εφαρμογή που περιγράφουν.

## Backup

Αντιγραφή του φακέλου με σταματημένο τον server αρκεί. Με τον server σε λειτουργία:

```bash
cd Backend
python manage.py dumpdata content --indent 2 -o ../Database/backup.json
```

## Παραγωγή

Στο production όρισε `PROTECTED_MEDIA_ROOT` στο `.env` σε φάκελο **εκτός** του
document root του web server, ώστε ο Apache/nginx να μην μπορεί να σερβίρει τα
αρχεία παρακάμπτοντας το Django.
